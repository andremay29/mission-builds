# Contributing

Thanks for building along! This repo follows the channel, so the main code changes come from each new episode. You can still help:

- **Found a bug or a confusing step?** Open an issue and say which log, what you expected, and what happened. A photo or the error message helps a lot.
- **Built something cool with it?** Open an issue with the "show and tell" label and tell us about it.
- **Fixing something yourself?** Fork the repo, make your change, run the tests, and open a pull request:

```bash
python -m unittest discover -s tests -v
```

Please keep code beginner-friendly: clear names, a comment for anything surprising, and the ROBOT CONFIG section at the top of every robot program. Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).
