# Mission 02: Cyberdeck

A **cyberdeck** is a small computer built into a rugged case: here, a Raspberry Pi with a 7-inch touchscreen and a mini keyboard inside a hard case. It becomes the rover's **mission control**: you code the rover from it, run the pre-flight check, and launch missions with a countdown clock on screen. The last episode links it to the rover for live data.

## Don't have a 3D printer?

You don't need one. Lots of **public libraries** have 3D printers you can use for free or a small fee. Mission Builds prints its screen case at the library in Log 03, and the guide includes the questions to ask before you go. No library printer near you? The guide also covers an online print service and a ready-made case that needs no printing.

## Budget

About **$280** in parts as of October 2026, or about **$194** if you use an old iPad as the screen. Raspberry Pi prices went up several times in 2026, so check current prices. The full list with links is in the build guide.
